# Agentic Pitch Clinic

A multi-agent coaching workflow combining classification, specialist routing, structured outputs, an evaluator-optimizer loop, and an MCP-hosted rubric tool.

## What it demonstrates
- OpenAI Agents SDK
- Pydantic structured outputs
- Routing across consumer, B2B SaaS, and deep-tech specialists
- Evaluator-optimizer iteration
- FastMCP rubric retrieval
- Multi-step agent orchestration
