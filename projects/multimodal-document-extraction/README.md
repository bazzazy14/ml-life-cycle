# Multimodal Document Extraction

Vision-language workflow for converting expense-document images into structured data, validating extractions against the original image, and analyzing spending patterns.

## What it demonstrates
- Base64 image encoding
- GPT-4o / GPT-4.1 multimodal API calls
- Structured JSON extraction
- Pandas transformation
- Second-pass multimodal validation
- Financial consistency checks
- Spending-category analysis

For the polished recruiter-facing implementation, see the separate repository: [multimodal-document-intelligence](https://github.com/bazzazy14/multimodal-document-intelligence).
