# Document RAG System

Retrieval-augmented generation workflow using document chunking, OpenAI embeddings, Chroma vector search, top-k retrieval, grounded generation, and query rewriting.

## What it demonstrates
- Recursive text chunking with overlap
- Vector indexing with Chroma
- Similarity-based top-4 retrieval
- Prompt grounding to reduce unsupported answers
- Query rewriting to improve retrieval quality
- LangChain runnable composition
