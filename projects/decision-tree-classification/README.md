# Decision Tree Classification

Supervised-learning workflow using customer churn data to prepare mixed-type features, train Decision Tree classifiers, and compare model performance across tree-depth settings.

## What it demonstrates
- Missing-data handling
- High-cardinality categorical feature handling
- One-hot encoding
- Train/test splitting
- DecisionTreeClassifier
- Hyperparameter comparison
- Accuracy-based evaluation
