# Model Context Protocol (MCP) Server

Built local FastMCP servers and connected them to OpenAI Agents SDK clients, including stateful sticky-note and todo-list tools plus a hosted MCP repository exploration workflow.

## What it demonstrates
- FastMCP server creation
- Typed MCP tools for add/search/delete and task management
- MCPServerStdio client connections
- Agent tool discovery and invocation
- Multi-turn stateful interactions
- HostedMCPTool integration
